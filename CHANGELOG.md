# Changelog

All notable changes to Tripzy Tours will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

---

## [v0.1.0] - 2026-07-09

### Added

- Initial project scaffold with Next.js 15 + TypeScript
- Supabase authentication (email + Google)
- Prisma ORM with PostgreSQL schema
- Vehicle catalog and search functionality
- Booking engine with date selection
- Cashfree payment gateway integration
- Admin dashboard with KYC review
- Fleet management system
- Cloudinary image upload
- Google Maps integration
- Landing page with hero, featured vehicles, testimonials
- Responsive UI with Tailwind CSS + shadcn/ui

### Infrastructure

- Vercel deployment configuration
- CI/CD pipeline with GitHub Actions
- Vitest unit test setup
- ESLint + Prettier code quality tools
